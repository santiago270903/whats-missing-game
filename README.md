# What's Missing? – juego para clase de inglés

Sitio estático (un solo `index.html`). Desplegar en Render:

1. Crea un repositorio en GitHub y sube estos archivos (`index.html`, `render.yaml`).
2. En https://dashboard.render.com → **New** → **Blueprint** → elige el repositorio. Render lee `render.yaml` y crea el sitio estático.
   (Alternativa: **New → Static Site**, Build command vacío, Publish directory `.`)
3. Render te da un link tipo `https://whats-missing-game.onrender.com`.

Cada `git push` vuelve a desplegar automáticamente.
